# RakFort Software Requests

## Approved software (self-service)
Staff do not have administrator rights on RakFort laptops. Approved software is installed through the **Company Portal** app:
1. Open **Company Portal** from the Start menu.
2. Search for the software.
3. Click **Install**. Installation happens in the background.

Common approved apps include Microsoft 365, Zoom, Adobe Acrobat Reader, 7-Zip and Notepad++.

## Software not in Company Portal
1. Raise a software request ticket at **https://support.rakfort.example**
2. Include the software name, the business reason, and your manager's name.
3. Your manager must approve the request.
4. Paid software (for example **Adobe Photoshop**) also needs licence approval and normally takes **3-5 working days**.

## Not allowed
- Installing software from personal downloads or USB drives.
- Browser extensions that are not on the approved list in Company Portal.
