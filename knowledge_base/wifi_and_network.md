# RakFort Wi-Fi and Network Guide

## Office Wi-Fi networks
- **RakFort-Corp**: for RakFort laptops only. Connects automatically using your work account - no password is needed. Do not connect personal devices.
- **RakFort-Guest**: for visitors and personal phones. The password is available from **reception** and changes **every Monday**. Guest Wi-Fi has internet access only, with no access to internal systems.

## Laptop can't connect to RakFort-Corp
1. Check that Wi-Fi is turned on and airplane mode is off.
2. Select **RakFort-Corp** and click **Connect**.
3. Restart your laptop - this refreshes the network certificate.
4. If it still fails, connect to **RakFort-Guest**, then use the **VPN** to reach internal systems while you wait for a fix.
5. Raise a ticket and include the exact error message.

## Wired network
Every desk has a network port. Laptops plugged in by cable connect automatically.
